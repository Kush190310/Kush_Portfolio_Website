# Kush Chaudhari — Portfolio

A personal portfolio website for Kush Ajitkumar Chaudhari, an AI/ML engineer and software developer pursuing a Master of Applied Computer Science at Concordia University. The site highlights his experience, education, skills, projects, and contact information.

## Features

- Responsive portfolio with About, Skills, Education, Experience, Projects, and Contact sections
- Dark and light themes, plus a mobile navigation menu
- Animated role title that respects the visitor's reduced-motion preference
- Downloadable resume

## Tech stack

- React 19
- Vite 8
- CSS

## Getting started

Install [Node.js](https://nodejs.org/) and npm, then run:

```bash
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |

## Project structure

```text
public/       Static files, including the downloadable resume
src/          React application and source assets
index.html    Application entry HTML and page metadata
```

## Resume

Replace `public/Kush_Resume.pdf` to update the resume offered by the website. The resume is served from the public root as `/Kush_Resume.pdf`.
